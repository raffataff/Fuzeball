## Conventions
- Plain non-module scripts sharing one global scope: a top-level `const` is visible in later files and **a duplicate top-level name anywhere throws**. Never convert to import/export (breaks `file://`). Element ids are globals too (`#lgGoals` = `window.lgGoals`): never name a function after an id.
- Dense terse style, `'use strict'` per file, short names, packed statements; match the surrounding code. `config.js` is the exception: spaced, one-line comment per value.
- Comments: only section titles (`// --- reaction latency ---`) and one-line notes on a non-obvious line or on what a higher/lower value does. No paragraphs, change-log/diary text, post-mortems, or restating code. The why goes in `docs/CLAUDE-history.md`. Trim comments to this rule in any function you touch.
- Globals (core.js): `$` = getElementById, `clamp`, `lerp`, `lerpAng`, `rand` (**not seeded**).
- When updating a function, rewrite the WHOLE function, then re-read it in context (owner pref).
- New tunables go in `CONFIG` (`js/config.js`), never inline. The aliases at its bottom (`F`, `BALL_R`, `KICK`, `AIC`, `SHOT`, `DIFFS`…) are derived: edit CONFIG. Check the object for a same-named key first: a duplicate key silently wins (happened with `shots.pin.down`, `fx.boost.ring`).
- Every optional module hangs off one nullable gate on `S` (`S.trn`, `S.trial`, `S.tut`, `S.photo`, `S.redit`, `S.lg`), tested only by that module + one-line hooks. A missing optional file must never break a match. Core, unguarded: `rng.js`, `shots.js`, `binds.js`, `padnav.js`.
- New cfg key → `CFG_PLAYER` (Steam Cloud) or `CFG_MACHINE`. New per-rod timestamp field → reset it in `resetRodRotation` (a stale stamp from the last match blocks until `S.time` catches up). A hard set of a ball's position outside physics → `syncBall(b)`.
- Concise, direct replies (owner pref).
- Mixed line endings (some `js/` files are CRLF): a multi-line find/replace written with `\n` silently matches nothing. Use Edit or splice by line index.
- Room notes go in the comment ABOVE `CONFIG.rooms`: the room editor's export drops comments inside entries and unknown keys (why `audioMix.reverb.rooms` and `CONFIG.atmos` live outside it).

## Coordinates, table, rods
- X = long axis (goal to goal), Z = width, Y = up, pitch at y=0. Dimensions in `CONFIG.table`, physics in `CONFIG.physics`: read them there.
- Goals at x=±L/2. Ball into the **right** goal → team 0 (red) scores; left → team 1 (blue). Easy to get backwards.
- Team 0 red attacks +x, team 1 blue attacks −x. 8 rods, 1-2-5-3 (GK, DEF, MID, ATT), 15 apart, interleaved: red GK −52.5, red DEF −37.5, blue ATT −22.5, red MID −7.5, blue MID +7.5, red ATT +22.5, blue DEF +37.5, blue GK +52.5. Men apart: MID 11.9, ATT 18.5, DEF 24.
- Rod: `pivot` (`position.z` slide, `rotation.z` angle), `men[]`, `baseZ[]`, `maxOff`, `offset`/`target`, `angle`/`angVel`, `kickT` (−1 idle), `kickA0`, `raise`, `act` (AI action), `hold`, charge `chg`/`chgSrc`/`chgA`/`shotOn`/`shotPow`/`shotCtl`, pin `pinB`/`pinOn`/`pinPose`/`pinFwd`/`pinA` (ball side `b.pinR`). AI `rel` = ball x from the rod, dir-relative (+ = ahead).
- Foot = an oriented box per man (`footBox`, `footBoxOff`) with priority over the leg capsule. Guards that test only the box miss the leg (`shotLegClips`).

## Core systems
**Sim.** Fixed `1/CONFIG.sim.hz` (120, keep it) with render interpolation (`b.prev`/`b.cur`, rod `iPrev`, angles via `lerpAng`). Adaptive substeps (`subTravel`, up to `subMax`, `PHYS_Q`); friction `exp(k·h)` per substep (substep-invariant); rods posed per substep. Spin/Magnus is a pure horizontal rotation (no energy): keep it. A slow frame runs up to `sim.maxSteps` steps, so per-step costs multiply when frames are slow. Physics is not the frame cost.

**Seeded randomness (`rng.js`).** Anything that changes an outcome draws from a named stream (`RNG.<tag>`, per-rod AI streams); cosmetics use `Math.random`. `S.seed` = live match seed; `S.seedNext` consumed once by `startMatchNow`; `rngSeed` clears cached streams (a retry must replay).

**Contact (`collideRod`, physics.js; two passes, change both).**
- Contact velocity = rotation (the swing, in full) + slide (`cvz` × `kick.slidePush`). `holdCfg(r)` = sticky contact for AI trap/dribble and the player's hold. `aimAssist` / `wallAssist` bend strikes (pure rotations); `aimAssist` reads `r.aimEv.best.tz`.
- Foot box: dead (`kick.rest`), gripping (`grip`), sweet spot, assist. Leg capsule (pivot→foot, `physics.prad`): bouncy (`kick.capRest`, `capGrip`), only where the box doesn't reach; `capDeadPosed` false. Both sized to the drawn figurines. A swing inside its power window (`restPower`) and `holdCfg` bypass this. Not built: elliptical leg, a rod that gives under a pass.
- Side bounce (`kick.sideRest`, `sideDot`, `sideBounce`): a ball rolling along the rod bounces off a man's ±z faces. This is what makes tic-tac work: a down man bounces it, a raised man lets it through, a raised-back man lets it under then pins it. Only the ball's own approach rebounds; the front touch stays dead; the player's hold fades it with the squeeze (`h.sideRest`); heavy balls plow. `sideRest = rest` = off. Untried: bouncing the front face.
- Rear (`kick.rearDot`, `rearCarry` 0): a backward-normal contact damps the ball's z instead of dragging it with the slide (that drag was the "glued to the back of the feet" bug), except on a posed rod (`r.pinPose`: the cushion needs it).
- Speed ceiling (`kick.cap`, `capSpeed`): the toe (~240 u/s) outruns a capped ball (~104) and re-hits it ~20× a swing. `cap.keep` / `held`: a ceiling-clipped re-hit of a ball already near its exit speed keeps its arrival heading, no assist or jitter (without it every off-centre kick left straight). `cap.pin` (a pin shot is a push of ~40 contacts; the shot trim is spent on the first), `cap.charge` / `chargeTop` (`r.swOver`), `cap.snake`. `cap.on:false` is unplayable (scoops, balls out). `stepBall` maxV 200.
- Boost (`boostSwing(r)`): only a STRIKE (leg turning forward in a kick `kickT>=0` / `shotOn`, or a pad stick faster than `kick.boostSwingW`, not `pinMag`) gets `KICK.boostHitMult` / `C.boost`.
- Rim (`tables.<id>.wallH`, `WALL_H` set in `applyTable`, `physics.rimW`, `rimLand` / `rimSeg`): the physical wall is as tall as the drawn one; a ball that clears it (`b.outWall`) lands on a round cap and rolls off. rim-harness reads the table GLBs. Not done: the arena lip has no rim; circuit `endWall.h` 0.6 over the drawn wall; the `C` overlay draws walls at `CONFIG.table.wallH`.

**The pin** (physics.js `pinUpdate` / `pinBallStep` / `pinRelease` / `footUnder` / `footBoxD`; `CONFIG.shots.pin`). The carry runs outside the contact solver on purpose (a boot pressed on a ball squirts it out). A ball is held when it touches the FOOT BOX (`touch` = contact tolerance, not reach) from above (`down`) with its centre under the sole. Windows: back `back..front`, forward `fwdBack..fwdFront`, picked by the leg's lean. Caught when its speed relative to the rod is under `capV`. Nothing moves leg or ball after a catch (no settle, no pull-in). `footAngle(rel)` (ai.js) = the pose that puts the foot on a ball's top; from rel ≈ −1.0 to +2.5 no pose can (shin/ankle first). One ball per rod (`r.pinB` ↔ `b.pinR`). Released by finesse up, any swing, the rod turning off it, a knock, a hard set, a side wall. A player's let-go keeps the slide of the last four steps (`r.vzH`). `pinSwing()` = the pin shot curve (`shots.pin.swing`: slower than trapShot so the boot doesn't scoop it over the bar) or the pin pass (`shots.pin.pass`, no wind-up: a pull-back swings the boot through a deep ball). Ring under a held ball (`pinMarkUpdate`, `pinRings`, `pin.mark`) and HUD plate (`hudPinHint`, `pin.hint`, `cfg.pinHint`) both ask `shotPinBall(seat)`.

**AI (`ai.js`, `CONFIG.ai`; `catch` below = `ai.catch`).**
Per active rod: ball seen through a reaction-delay ring (`aiView`), align a man (hysteresis, deadzone, drifting error), pick an action: `lane`, `catch` (all phases below, `r.catPh`), `retrieve`, `safeRaise`, `evade`, `dribble` (+pass), `recv`, `run`, kick (`trap` off). Two hands per team (`ai.hands`); human-held rods are forced active. Tallies `CAS` / `CAW` (catch), `BGS` (back guard, retrieve).
Lessons that keep coming back:
- Static vs swept reach: `inFootRange` is static; anything that ROTATES the rod needs `sweepClips` + the leg, or the boot drags the ball goalward. A leg turning forward from rest sweeps through a ball ahead and blasts it: take a ball ahead from above.
- The kick gate is a snapshot: aimed/slow swings re-check with `strikeOn` / `strikeProbe` (they take a curve; `strikeGate.lead` covers `trapShot` having no wind-up).
- Back guard (`ai.backGuard`; `backLimit` / `slideBlocked` from `updateRods`) is the last word on AI back-lift and slide. Any boot contact hands the ball the boot's velocity; a lift is safe only with the man z-clear until the boot is over the ball (`safeRaise.angleBehind`); the arc is sampled by angle (`arcStep`); the lift is timed by the real exponential ease; a ball inside the box reads as ahead (`deepD`); a held lift stamps `r.lhT`. Exempt: kick swings, trap, dribble, pin, human rods, except a human leg coming back from the forward pin (`backLimit(...,own)`, `r.fwdOut`) and any drop from a forward pose to rest (`backLimit(r,0,dropLerp)`).
- Read the REAL ball (`best.real`) in a phase that follows a contact (side catch, thru, tap, retrieve after a lift via `retKnow`): the delayed view still shows the old state.
- Never extrapolate a held rod with `laneObs`'s `vz` over ~0.1 s (AI slide is bang-bang). `ttObs` reads `target + r.tgV`.
- `pinUpdate` runs at the start of the NEXT step after `aiUpdate`: a ball stopped dead in one step needs the pose kept a moment (`recv.rest`) or the action ends first.
- Exits go through `catchEnd` / `retrieveEnd` / `recvEnd` / `runEnd`. `clearRodAI` (seats.js) wipes AI state when a human takes a rod.

Actions:
- **Raise back** OFF (`ai.raiseBack`): a ball from behind never raises a rod (`raiseBehind` latch, `rodHoldRaise`, `clearLane.lift` gated), so receivers stay down. Not gated: safeRaise, retrieve, evade's own raise. Training's LIFT toggle is `rodHoldRaise` (no-op while off). Unbuilt idea: raise FORWARD for a ball too quick to pin.
- **Retrieve** (`ai.retrieve`, `retrieveStep`): slow ball behind the heel: side (never crosses a ball nearer `crossRel`) → lift → over (`backHit`) → pin (keeper/smart rods, then `pinPlay`) or drop (boot sweeps through). The pin pose must lead the boot by less than `shots.pin.capA` (`pinLead`). `r.catUntil` keeps its iq gate off when the catch hands over.
- **Catch** (`catchPick` / `catchStep` / `pinPlay`; any rod, `catch.iqGate:false`): pins with the player's pin. Front (ball from upfield, posed at `catch.front.angle`), behind (ball from the rod behind: heel stop then retrieve, or the forward receive `r.catFwd`), then side, meet, fetch, ahead, tap, hit, tictac, flift, hold, thru.
  **`pinPlay` order**: open shot (ATT: line to goal + mouth; others: `fwdClr` gap past the row ahead; `lineClear`) → tic-tac (`tictac.first`) → carry (`pinCarryEval` / `pinTarget`, `flipGain`, `catch.turnT`) / tap → pass (`passPick`; `catch.open`: GK/DEF pass an open lane when a mate is on offer and never push; MID passes only when the mate clearly beats the lane; `carryFirst`) → wait `holdT` → play anyway. Lanes are judged with the opposing rows where they will be (`laneObs` / `fwdClr`, `v0 = catch.shotV`).
  **Push** (`catch.push`): a shot fired while sliding over `minV` keeps `carryOut` of the slide; `r.catSv` / `r.catSw` hold the slide through the swing; the lane is judged from `drift` on `pushSlope`. `pinAim` puts the aim point on the judged line (else the assist bends pin shots ~8° to the middle).
- **Side catch** (`catch.side`; `sidePick` / `sideStep`): a ball rolling along the row: men up, the pose drops at `footAngle` `dropT` before it arrives (`side.topGap` above it); depth limit `shots.pin.back`. Cushion: the rod runs with a quick ball (`cushionT`, `cushionW`, `cushionV`, `cushionD`, `cushionRoom`, `cushionSlack`); the pin judges speed against the rod's. Never start the pose early for a quick ball (breaks taps). `legD` clears the foot box. `sideAngle(rel)` is only the tic-tac strike tilt / let-through pose now; `side.back` is the shallow/deep line tap and hit use.
- **Tap, the roll** (`catch.tap`; `tapEval` / `tapStart` / `tapStep` / `tapSide`): a stuck pin carries the ball along the row and lets go at `releaseV` of the carry; the neighbour takes it as a cushioned side catch (`catPh` tap→side→hold). Bands: shallow, `tap.deep` (`deep.back`, `r.catDeep`), `tap.fwd`. `maxChain`. `tapStart` tries the hit first. Retrieve's pins tap via `retrieveTap`. `tapSide` must NOT drop the pose in the release frame (the boot swings through the ball).
- **Tap back** (`tap.back`; `backEval` / `backStep`, hook in `sideStep`): receiver's lane shut and sender's open → the sender's men go down with the boot square to the ball (`asin((rel - footBoxOff.y)/(ARM + footBoxOff.x))`; an upright boot's corner knocks it backward), slide in (`runD`, `runV`), decided at least `tMin` early. DEF/MID; ~never in AI matches.
- **Meet** (`catch.meet`; `meetPick` / `meetStep`): a slow ball along the row nobody will roll into: the nearest man AHEAD of it (never behind: a chaser pushes it) slides to it fast, then closes at `closeV` from `slow`; no man within `clear` of its z. For human balls.
- **Fetch / ahead** (`catch.fetch`; `fetchPick` / `fetchStep` / `aheadStart` / `aheadStep`): a slow loose ball `near..far` ahead with no shot: clear → up (`recv.lift.angle`) → over (slowly) → down onto its top → forward hold. A swing play from a ball held over `fetch.aheadMin` ahead: let go, step off, lower, step back, swing. `r.ftCd` (`fetch.cd`). A `stopped` catch hands over to fetch at once; `catch.liftY` stops a hopping pass ending a catch. The toe pin was built and removed (a running ball meets a raised leg's front, not its top).
- **Hit, the tap proper** (`catch.hit`; `hitAngle` `hitStand` `hitFits` `hitOk` `hitStart` `hitGo` `hitStep` `hitLoose`; `r.hPh` rest→clear→aim→run→out→`tapSide`): the foot's ±z face knocks the ball to the neighbour. `hitAngle(rel)` squares the box on the ball's depth (null past `fit`, about ±3.95). The foot must be still at contact (`tolW`, `tolA`) or it hands the ball x speed. `hit.bands`. A forward-held ball is let go with `fliftStart(r,'hit')` first. `hit.loose`: a ball at rest between two men, no shot. Switches `hit.on`, `share`, `loose.on`.
- **Tic-tac** (`catch.tictac`; `ttVal` `ttRoom` `ttSlides` `ttPick` `ttWant` `ttLoose` `ttRoll` `ttStart` `ttGo` `ttCatch` `ttObs` `ttOutlet` `ttPlan` `ttOpts` `ttBest` `ttStrike` `ttRevert` `ttStep`; `r.ttPh` bounce|strike): the default play for a held ball on every row (`first`, `roles`, `byRole` pace/room: MID slower), from back, forward (`fliftStart`) or ahead pins, a loose ball (`loose`), or a ball rolling along the row (`roll`, straight into the bounce). Two neighbouring men, feet squared (`hitAngle`; `square` between touches); the face the ball rolls to slides into it (`pace`, `lunge`; `meet` for slow balls); `homeV` drifts the pair onto the goal, kept `lungeRoom` off the slide ends. Band: start `relMin..relMax`, live `offMin..offMax`.
  **Strike**: the leg tilts back to `sideAngle` before the ball reaches the face (`tilt`, `late`; `tictac.lerp` = AI tilt rate, the player's pin keeps `shots.pin.lerp`), a `trapShot` swing at `gap`; the ball leaves with ~0.9 × the slide sideways (`strike.k`); a slide with the ball at most `pushMax` of its speed. Two stages: the leg commits when a lane clears by `prep` (after `warm` touches); each frame rereads the rows (`ttObs`, `tgtLead`), changes slide only for `stick` better, needs `go` at the last moment, gives up past `drop`; revert (`back`, `untilt`, `relock`); `patient` / `ease` relax it in long rallies. Let-through (`thru`, ATT only, `thru.minV`). Every end that keeps the ball is `ttCatch` (a side catch). `maxT`, `maxTouch`, `cd`, `cdTime`. Measured and rejected: a dink and a pass out of a MID/DEF rally (the swing's clean steering window is ≤12°). Not built: MID let-through, a rally from a deep retrieve pin.
- **Kick heading**: the foot face is flat, so a plain kick's heading comes from the rod's slide through the strike, the assist (`assistAng`, by the acc stat) and the ball's own lateral speed, not from the lane the AI judged. The soft pass swing's heading follows the slide (~0.92 × slide sideways) but reaches the ball ~0.17 s after it starts, so the slide must be COMMITTED through the swing. Never gate a kick on the slide or the ball's lateral speed dying. `ai.aimCone` OFF (the cone alone made things worse). After any kick the other team touches first ~90% of the time (interleaved rows).
- **Pass steer** (`catch.steer`; `steerHeading` `steerSlide` `steerV` `steerReach`): a pin pass commits a slide toward the mate, held `hold` s (needs room; `vMax`); `passEval(...,pin)` offers only mates within `steerReach`. **Free-pass run-up** (`steer.free`; `freeBall` `runV` `freeReach` `runPlan` `runStart` `runMate` `runStep` `runEnd`, `r.act==='run'`): a slow ball 3-5 ahead: back off, run at it, fire when `z_man + slideV·lead ≥ z_ball`, re-check the planned mate (`thTol`); DEF only in practice (needs travel); no run possible = a plain kick. Not done: MID, dribble-release passes, moving balls.
- **Receive** (`catch.recv`; `recvArm` (from `kickRod`) `recvBall` `recvStart` `recvStep` `recvEnd` `recvRest` `reseat`; `r.act==='recv'`): the target rod holds a forward pin pose (`recv.angle`, the same number as the player's) with the man on the ball's line (`catchMan`); ends pinned / taken / through / time / reach / `maxY`. `rest` keeps the pose for a ball lying stopped in the window.
  **Ready** (`recv.ready`; `recvReady` `recvPossess` `recvOwn` `recvReadyNow` `recvRelease`; `r.rvReady`): rods ahead stand posed when a holder looks at passing (`rvLaneT`), on possession, or (`feet`) any slow ball near one of the team's rods (`feet` costs some dead balls, cause unknown). A pin pass WAITS for its receiver (`wait`), holding still. Any non-pass kick releases the mates ahead (`release`), except a keeper's kick with a ball already running at a mate. Own ready rods are lane obstacles in `laneObs` (the target rod excluded). `reachT`, `cd`, `liftT`, `ready.arrive`.
  **From under a forward leg** no swing is possible (the wind-up sweeps through the ball): a shot is the ATT's snake, else `reseat` (let go, retrieve re-pins) via the forward lift (`recv.lift`; `fliftStart` / `fliftStep` / `reseatGo`; `flNext` tap|retrieve; `r.retFl`, `retKnow`). `recv.fwdBrake`: no swing play while sliding over `fireV`. A forward pin is held `recv.settleT` and carried at `recv.carry`. `recv.take` (`takeFwd` / `catchUp` / `thruStep`; `take.thru` OFF), `recv.tap`.
  **Keeper's kick** (`dribble.pass.gk`, `gkHold`): passes to the DEF nearest straight ahead within `gk.maxTh`; waits `gk.readyT` / `clearT` for a ready DEF to clear the lane; `gk.on:false` = old. Open: `passShot.strike` / `powTo` 0.15 sends passes at 77-97 u/s and the MID pins ~17% of DEF passes (0.20 pins all); not changed.
- **AI snake** (`catch.snake`; `snakeHold` / `snakeFire`): a SHOT from a forward hold is the player's snake. ATT only (`roles`; MID/DEF snakes are clearances that cost at legend), depth `relMin..relMax`, `use` by difficulty (drawn once a hold, `r.pcSnD`). Slide carried through (no fwdBrake); lane via `pushOutlet` with `r.pcSn` (`drift`, `k`). A pass from a forward hold still re-seats. Not done: setting up a hold in order to snake; a snake pass.
- **Dead-ball push** (`ai.force`; `deadLeft(b)` in powerups.js = real seconds to the whistle, also on the `C` overlay): ball in a rod's own strike window and `deadLeft < force.left` → `r.force`: square up and kick/pass now, skipping cooldowns, retrieve, the sweet-spot wait; may slide through a ball beside its heel. Per rod (a ball-wide flag made every rod abandon its line).
- **Keeper safe-raise** (`safeRaise.gkAlways` / `gkLerp`, `srLerp`): the keeper lifts for a ball crossing its front/heel, no iq roll, fast. −1.0 blocks the pocket, −1.3 is over it. `safeRaise.gkIn` (`srGoingIn`): no lift for a shot going in.
- **Goal cover** (`ai.cover`; `coverZ` `coverFit` `coverReach` `coverEye` `coverSlide`): GK + DEF body shadows on the goal line fitted for the smallest, evenest gaps (grid + polish, `travel`). Modes: pair / keeper covers while the DEF plays (`playReach`, `nomAhead`) / wide (`gkWide`, `r.cvW`). ## Controls
**Seats (`seats.js`).** `S.seats[]` = every human: team, claimed devices (`kbd`, `mouse`, `padN`, `pad*` = first pad), held rod. A solo seat holds keyboard + mouse + pad. Resolve device → seat → rod: `seatForDev`, `seatRod`, `seatOf(r)`, `isUserRod(r)`. `userRod()` / `S.userTeam` = the PRIMARY seat only. Up to 4 a side.

**Auto rod-switch zones** (`CONFIG.control.zones`; `zoneAt` `zoneDef` `zoneNear` `zonePick`, used by `userControlUpdate` and `autoHoldRod`): two painted 48×28 maps (a string a row of `G D M A .`, from red's end; blue reads them turned round): `def` while the other team has the ball (`S.lastTouch` / `b.pinR`) or it runs at our goal faster than `closing`, else `att`. `.` or an untakeable rod falls back to nearest in x (the old rule). `hyst` keeps the held rod. Shipped maps = the old rule (harness checks); not painted yet. Painter: `C` overlay → AI DEBUG → Rod Zones (`buildZonePanel` / `dbgZoneDraw`; COPY gives the config block). A band painted just past a pin spot is eaten by `hyst`.

**Bindings (`binds.js`, `CONFIG.binds`, `cfg.keyBinds`).** Every rod action is a binding (key code, `Mouse0..4`, `WheelUp/Down`); the binding's device decides the seat. Defaults: arrows/W-S or mouse slide; ←/→, A/D, Q/E or wheel switch rod; Space/LMB kick; L-Shift/RMB raise; R-Shift power; R-Ctrl finesse; 1-4, B guide, V camera, R retry trial, S save clip, M next music track. Reserved: Esc, F1, F2, F3, dev keys C/L/F. In a match every bound key is `preventDefault`ed; Alt and F10 are swallowed on down and up (they steal focus and drop pointer lock). `modSync` reconciles modifiers from every event (Windows drops one Shift's keyup while the other is held). A raise press is latched (`s.rzEdge`). Ctrl+W/T/N must be blocked by the Electron shell.
Pointer lock (`mouseLockWant` / `mouseLockTick`): wanted through play/count/goal/replay while a seat holds the mouse; re-asked every 250 ms; a refusal latches `mlRef`; `body.mlHide` hides the cursor regardless. Pause, win, menus, cards, the training panel, click-place and the zone painter want the cursor.

**Shot verbs (`shots.js`, `CONFIG.shots`; `shots.on:false` = pre-shots controls).** One step per seat per frame (`shotSeatsUpdate`, after `gamepadUpdate`): each device reads into a record and the step runs on the merge (a per-device machine releases the other's charge). Physics reads only `r.shotOn` / `shotPow` / `shotCtl`, spent by the first contact. Tremble is display-only.
- **Axis** = power − finesse (RT − LT, R-Shift − R-Ctrl), −1..1, blends the swing curve; both held cancels.
- **Charge** (`charge.needRaise`): power + a pull-back (KBM power + raise; pad RT + X or RT + right stick back; Total Control both triggers) winds up; only a kick fires it; letting go cancels and disarms (`charge.grace` for a late kick). Power is the ARC (`kickA0` → strikeA over a fixed window); the sweet band is a flat max, overcooking falls off. Don't stack restitution multipliers.
- **Back pin** (finesse + raise; pad LT + X, or the right stick in `pin.band`): poses at `pin.angle`; gated on finesse DOWN (`I.fin`), not the eased grip. Kick from it = the pin shot (`shotPinFire`, `pinSwing()`, ignores the axis); slide then kick = push/pull.
- **Forward pin** (finesse + kick; pad LT + A; `pin.fwd`; `shotPinFwdPress` `shotFwdAngle` `shotFwdBall` `shotFwdHold` `shotFwdSweep` `shotFwdUnder` `shotFwdLead` `shotFwdZ`): a kick press with the axis at or under `pass.modAt` poses `r.pinPose` + `r.pinFwd` (+ `r.pinKh`); `fwd.on:false` gives back the old assisted pass (`shotPassPick`). The angle is geometry: the AI's fetch as a function of where the man stands (up beside a slow ball, down onto its top once over it, else `fwd.angle`), the man counted `fwd.lead` ahead.
  **Tap vs hold**: a tapped kick (under `hop.tap`) is the stroke, i.e. the pass (the leg sweeps through, straight, speed set by `fwd.lerp`; `msStroke` counts it). Held, it pins: a rise that would touch a ball is held (`r.fwdBlk`), the man steps off (`hop.v`, `clearOffset`), the settle brings him back over and the leg comes down at `pin.lower`. `assist.under`: a ball rolling at the man from ahead lifts the toe so it rolls under, then the foot comes down (`r.fwdU`). Kick held first (the swing frozen forward), then finesse: ends the swing (`kickT -1`, `shotDisarm`) and poses the pin.
  **Letting go** is the dangerous half: with `r.fwdOut` set, a ball lying `holdNear..holdFar` ahead slower than `holdV` (to the table OR the rod) sends the leg UP and forward (`shotFwdHold`) until the man is clear; anything else comes back through `backLimit(...,r.fwdOut)`.
- **Pin assist** (`pin.assist`, `shots.hold.lead`, `shots.square`; `shotPinAim` `shotBackAngle` `shotStickPin` `shotSettle` `shotSquare` `shotPinInput`): the back pin mirrors the forward one (leg `up` over a slow ball `pin.back..near` behind, down to `footAngle` once over it; never lowered through a ball it is under). Slide settle (`settle`): a leg posed over/beside such a ball with the slide still `still` s draws the man onto its z (up to `settle.z` off; moving the slide resets it; `r.stlW` moves with the lead clamp). `hold.lead` clamps the slide target to the rod while held or pinned. Stick settle (`stick`, both pad modes): finesse + the stick within `win` of the catch angle settles on `footAngle`; a pinned ball with finesse held keeps its angle until the stick goes `keep` past upright (a strike) or finesse is up (`r.pinMag`). Square (finesse alone): the leg turns to `hitAngle(rel)` for the nearest low ball beside a man (`back..front`, `zMax`) and holds for a ball in a man's lane (`r.sqA`). **Unlatched** (`pin.latch:false`): the back pose lasts while raise is held, the forward one while kick is; the latest press picks; let go with finesse held → the square, seeded at the current angle; a pinned ball keeps its pose.
- **Receive** (`pin.assist.recv`; `shotFwdRecv` `shotRecvAsk`, `r.fwdR`, `s.rcvAsk`, `s.rcvT` / `I.rcv`): finesse + kick both held is the forward pose whatever came first (`recv.take`). A low ball coming from behind (`far`, at least `minV`, under `ai.catch.recv.maxY`) poses the leg at `ai.catch.recv.angle` (one number for both; lower measured worse), rising at `recv.lerp`; the man whose slide reaches the arrival line is drawn onto it at `recv.v`; the grip doesn't slow a receiving rod. Finesse alone keeps the receive on for `recv.strokeT` after a stroke. The pin shot with kick HELD after it is a pass (received); tapped, a shot. While a seat asks (`shotRecvAsk`, `recv.mates`) its AI rods ahead stand ready (`recvPossess`, `ready.trackV`). No HUD cue for receiving.
- **Roll re-pin** (`pin.assist.roll`; `shotRollAngle`, `r.pinRl`): back pose with no slow ball → a low ball rolling along the row (|vx| under `maxVX`, over `minV`) reaching a man within `tMax` poses the foot at its arrival depth; a leg up over it drops at `roll.lerp` with no pull cap; the player's back foot catches such a ball up to `roll.capV`.
- **Snake** (`shots.snake`, `kick.cap.snake`; `shotKickEdge` `shotSnakeFire` `shotSnakeSeat`, rods.js `snakeStep`, physics.js `snakeLoft`): ball held under the forward leg, finesse held, a second kick press within `dbl` (`r.snPT`; the posing press doesn't count) → the man spins forward over the top and through past a full turn (`spin`, `follow`, `back`, `ease`). `r.angle` stays within ±π: the turn is one wrap with `prevAngle` moved too, so `angVel` and the substep lerp read it as continuous; render/replay use `lerpAng`. Ball let go with `carry` of its slide; the man slides at `pin.carry` to the strike. A foot faster than ~20 rad/s at the ball scoops it; `powTo` must stay past `spin`; `loft` turns a snake's climb down (pure rotation; `loft:null` = raw). `exert` stamina. HUD plate `[kick] x2 snake`; goal kind `snake` (`momKind`, `moments.lines.snake`). Not in the controller reference (a row there scrolls the panel at 1280×800), no tutorial lesson, no sound of its own.

## UI
- **Screens (`screens.js`)**: every navigable screen is one `SCREENS` entry (`showScreen` / `backScreen` / `hideScreens`); overlays (pause, win, dialogs) aren't. - **Layout editor (`layout.js`)**: a screen gets draggable panels from a `lay` block (or array) in its `SCREENS` entry. - **Plates (styles.css, FEDERATION PLATES)**: buttons, tabs, menu items, chips = two clipped pseudo-layers: a rectangle with top-left and bottom-right corners cut at 45° (0.66 × `--pc`, min 5px). Panel caption tabs (`.panel>h3`, `.slotNo`) cut only bottom-right; the screen wipe's leading corner uses the same cut. **Nothing slanted** (owner: 20° parallelograms read as generic AI design); the only exception is the HUD scoreboard. Style a plate ONLY through `--pl` (fill), `--pr` (rim), `--pc` (cut), `--pk` (text); a new plate control joins the `:is()` lists. Never put `background`/`border`/`clip-path` on the element (clip-path clips the pad focus). `.btn` = gold primary, `.btn.ghost` = blue secondary.

## Modes
- **Kick Off** (`roster.js`): per-player seat cards, press-to-join, 4-a-side local co-op.
- **League + Champions Cup** (`league.js`): the player is team 0; builds and upgrade parts. Rules (`lgGoalCap` / `lgMins`) belong to the save; the cup uses the league's. The venue belongs to the session (`lgVenueEnter` / `Exit`). The cup is a seeded tree.
- **Training** (`training.js`, `S.trn`): the sandbox.
- **Skill Trials + daily** (`trials.js`, `S.trial`): training with a rulebook. The clock is sim time from your side's first TOUCH (`trialGo` / `trialTouch`, hooked at collideRod's two contact sites and pinUpdate's catch; never `S.stats.kicks`, which misses stick swings, strokes, taps); a `saveRun` starts on its first serve; an untouched finish is timed from `TRL.r0`. Retry re-seeds from `S.seed` onto the same table (`trialHome`: rods home, `r.exert` 0, seats on the rod the ball lies in front of). `S.matchTime` held at 0 (no stamina ramp). Scored by time (lower) or `saveRun` saves (higher). Spawns must clear the resting foot box and stay in reach (the harness checks from live CONFIG). The daily is a pure function of the date.
  **Drills** (`goal.kind 'drill'`, `CONFIG.trials.drill`, `drill*` in trials.js, `TRL.dr`): nine per rod (TIC-TAC LANE, TIC-TAC STRIKE, BACK PIN, FORWARD PIN, PIN AND PLACE, PIN SHOT, WALK THE LINE, ROLL CALL, ROLL AND FIRE), browsed in sets (`CONFIG.trials.sets`, `trialSetsIn`). A goal counts from `b.mss` and how that swing began (`D.sw`). Facts behind them: a ball in a man's own lane can't be back-pinned (placed balls start beside a man); the assist pulls long pin shots to the centre (MID/DEF strike drills finish into an empty net); a tic-tac strike is finesse up, raise, kick as the ball reaches the foot. Medals from `trSeeds` bot medians (serve-paced 1.3/1.8/2.8×, others 2/3.5/6×; limits bronze × 1.25). **All medal thresholds are unplayed guesses.** Open: ATT TIC-TAC STRIKE bot 2/12 since `cap.keep` (ball served at z 9.25 goes into the post). Keys-only slides run at full speed only, so a roll is hard on keys.
- **Tutorial** (`tutorial.js`, `S.tut`, armed from `trainingEnter`): two courses (`TUT.course`, `tutList`): basics (`CONFIG.tutorial.lessons`) and Advanced Moves (`.advanced`, `btnTrnAdvanced`: forward pin, forward catch, pass and receive, pin pass, tic-tac, walk the ball). `#tutorial` picks KBM / Controller prompts (every device works). The basics are offered once before the first Kick Off / League (`tutOffer`, `cfg.tutSeen`); only the basics set `cfg.tutDone`. Text = the live bindings (`tutKey`: first key + first mouse input), rebuilt each frame, written only on change (`tutHudSync`, `tutHint`). Lesson fields: `auto` (`S.tut.auto`; clears `S.lastSwitch`), `row` (`rowBand`, `rowIdle`), `centre`, `ball.zRod`. Judged from the lesson's rod (`tutHome`). Progress `TUT.prog`. Balls sit on the near side (the panel covers the far third). Gotchas: letting go of finesse and raise together over a back-pinned ball swings the boot through it ("keep raise held"); a kick held past `hop.tap` in the receive lesson pins on the passer.
- **Replays** (`replay.js`): ring buffer re-posed from footage, with sound and saveable clips; the match winner gets one.
- **Photo mode** (F1, `photo.js`): stills, clips, offline turntables.
- **Room editor** (F2, `roomedit.js`, `CONFIG.debug.roomEditor`): exports paste-ready `CONFIG.rooms` blocks.
