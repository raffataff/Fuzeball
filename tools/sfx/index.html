History

SFX Lab

  • Kit: a set of sounds sharing one key and scale. Every pitch is a scale degree (0 = the key's root, 1 = the next note of the scale, -1 the one below), so sounds made here always agree with each other. Change the key or scale and the whole kit follows.
  • Layers stack sources: osc (sine, triangle, saw, square, pulse, unison), fm (glassy and metallic tones), noise (air, whooshes, static, crackle), pluck (a plucked string), modal (struck bells, glass, bars, membranes), add (harmonics you list). Each has pitch motion, an envelope, a filter with its own envelope and LFO, and mods (drive, ring, tremolo, bit crush, downsample, glitch).
  • Notes lists degrees played from the layer's root: 0 2 4 is a triad in the scale. Play: chord (together, Step = strum), arp (one after another), rand. Repeats echo the figure, Repeat shift moves each echo up or down the scale.
  • Master: EQ, chorus, ping-pong delay, reverb, width, and Normalise. loud sets the loudest 50 ms to the target, so short and long sounds sit level with each other. Balance levels puts the menu sounds on a loudness ladder.
  • Takes: the game round-robins takes. Take 1 is the recipe exactly; the others vary pitch, timing, filter and level by the Vary settings in Master.
  • Export to game writes assets/audio/ui/<id>_01.wav… and rebuilds the manifest. The id's old files are moved to tools/build/sfx-backup/ first. Reload the game to hear them. It needs node tools/sfx-server.js; without it you get downloads.
  • Keys: Space play, Ctrl Z / Ctrl Y undo / redo, Ctrl S save kit, Ctrl E export. Double-click a parameter's name to reset it. Click the keyboard strip to hear a note.
