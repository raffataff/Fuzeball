The bundled mask is approximate. I derived it from the render by colour-keying the teal, which is exactly the method you should not ship: the robe desaturates in shadow, so the shaded folds fall out of the matte and stay untinted. Cryptomatte has no such failure — it cuts by material ID, so shadowed kit is still kit. Use this page to judge the blend, then drop a real Blender mask on it to judge the matte.
